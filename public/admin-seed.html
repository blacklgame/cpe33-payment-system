Seed Users into Firestore

This reads every entry in user.js (your existing local roster) and writes it into the Firestore users collection, one document per Nu ID. Run this once after enabling Firestore.

Delete this page (or block it with rules) once you're done — it's not meant to stay live on a public site.

Before seeding: firestore.rules must currently allow writes to users (temporarily, for this one-time step) — allow write: if request.auth != null; — and be published in the Firebase Console. Lock it back to allow write: if false; once seeding is done.
