Seed Users into Firestore

This reads every entry in user.js (your existing local roster) and writes it into the Firestore users collection, one document per Nu ID. Run this once after enabling Firestore.

Delete this page (or block it with rules) once you're done — it's not meant to stay live on a public site.

Before seeding: firestore.rules must have this exact block published in the Firebase Console (Firestore → Rules → paste → Publish):

match /users/{nuid} {
  allow read: if true;
  allow write: if true;
}

This page does not sign in or check auth at all -- it writes as soon as you click the button. If it still fails, the rule above genuinely isn't live yet; that's the only thing left that can cause a failure here.
